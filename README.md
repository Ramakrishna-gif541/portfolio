# Ramakrishna Konda — Portfolio

Static portfolio site (HTML, CSS, JavaScript, Three.js). No build step.

## Run locally
Open `index.html` in a browser, or serve the folder:
```
npx serve .
```

## Put it on GitHub
```
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/Ramakrishna-gif541/portfolio.git
git push -u origin main
```
(Create an empty repo named `portfolio` on github.com first.)

## Free hosting (GitHub Pages)
Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
Your site will be at https://ramakrishna-gif541.github.io/portfolio/

## Edit
- Text and sections: `index.html`
- Colours, layout, animations: `style.css`
- 3D scene and contact form: `script.js`
- Replace the `[PROJECT NAME]` placeholders with your real projects, screenshots (put images in `assets/`), GitHub and live links.
